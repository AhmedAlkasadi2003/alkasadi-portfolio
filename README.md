# Ahmed Alkasadi Portfolio

Bilingual portfolio and interactive CV for Ahmed Mahfoodh Alkasadi, a Front-End Developer from Hadramout, Yemen.

## 🚀 Features

- **Multilingual Support (i18n)**: Fully supports English and Arabic with RTL (Right-to-Left) layout optimization.
- **Dark/Light Mode**: Seamless theme switching with system preference auto-detection.
- **Responsive Design**: Optimized for all screen sizes, from mobile to ultra-wide desktops.
- **Performance Optimized**: Static generation with Next.js and deployment-friendly local assets.
- **Interactive UI**: Smooth animations powered by `motion` (Framer Motion).
- **SEO Ready**: Dynamic meta tags and titles for every page.
- **Accessible**: Semantic HTML, ARIA labels, and keyboard navigation support.
- **Data Driven**: Centralized data management for easy updates.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS
- **Animations**: Framer Motion
- **Internationalization**: i18next
- **Icons**: Lucide React
- **Framework**: Next.js 16 App Router
- **Deployment**: Optimized for Vercel / Netlify / Cloud Run

## 📂 Project Structure

```text
src/
├── components/     # Reusable UI components
├── data/           # Centralized static data (projects, skills, etc.)
├── locales/        # Translation files (EN, AR)
├── app/            # Next.js routes and metadata
├── components/     # Reusable UI components
├── data/           # Ahmed's portfolio and CV data
└── locales/        # English and Arabic translations
```

## 🚦 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AhmedAlkasadi2003/alkasadi-portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
